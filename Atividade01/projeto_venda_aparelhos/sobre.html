🎬 Sobre este projeto

Este catálogo foi criado como uma atividade prática da disciplina de Programação para Web.

O objetivo foi aplicar os conhecimentos de HTML para desenvolver um pequeno sistema com:

  1. Tela de login simulada;
  2. Tela de cadastro;
  3. Navegação entre páginas;
  4. Iframe;
  5. Catálogo de produtos;
  6. Imagens;
  7. Tabelas;
  8. Listas;
  9. Links internos e externos.

Todo o projeto foi desenvolvido utilizando somente HTML, sem CSS e sem JavaScript.

🎯 Meu objetivo

Meu objetivo com esta atividade é aprender cada vez mais sobre desenvolvimento Web e melhorar minhas habilidades de programação.
